- [ ] Confirm the NASA POWER API choice is approved in Canvas.
- [ ] Install dependencies with `npm install`.
- [ ] Run with `npm start` and test all routes.
- [ ] Test valid coordinates and dates.
- [ ] Test invalid latitude/longitude and reversed dates.
- [ ] Test an unknown URL (404).
- [ ] Test API/network failure handling.
- [ ] Capture 2–3 real screenshots after running the app and add them to README.
- [ ] Review every file and make sure you can explain it without AI.
- [ ] Create at least 8 meaningful Git commits on different days (do not fake dates or commits).
- [ ] Complete the official AI Declaration template from the assignment.
- [ ] Create ZIP without node_modules and .env.
- [ ] Submit GitHub repository link, ZIP and AI Declaration in Canvas.
